horn — an experimental microkernel-based operating system

horn is an attempt at making a functional desktop (and server!) microkernel-based operating system. It's in the very early stages and is unlikely to be finished any time soon.

Nevertheless, you can check the RPC interfaces or download the latest CI-built image.

Plans

We plan to use an L4Linux-like approach for app compatibility, making the Linux kernel an ordinary seL4 task.

The desktop version will include a ground-up implementation of the NVIDIA driver with a compatibility layer inside the Linux kernel to make ordinary NVK work. This approach allows one native driver to serve both native horn tasks and ordinary Linux apps, providing isolation while keeping overhead minimal.
